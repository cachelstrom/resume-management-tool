## Reference-Only Skills — Do NOT Use for Core Skills

These additional terms appear in experience notes or historical resume variants but are not on the current Core Skills allowlist. Keep them here for a fuller record. **Do not add them to a generated resume's Core Skills section unless the user explicitly moves them to the approved section.** A role-specific resume bullet may still describe documented work with one of these tools when supported by the relevant experience note; do not use this inventory alone as evidence of hands-on proficiency.

> This section is a holding area, not a rejection of the underlying experience. It includes skills named in historical resumes and tools or systems described in role notes. Confirm each item and promote it by moving it to the approved section if it should be eligible for future Core Skills sections. Remove items that are inaccurate or no longer relevant.

## Maintenance Rules

- Keep the two lists mutually exclusive.
- Add a skill to **Resume-Approved Skills** only after the user confirms it is appropriate for resume Core Skills.
- Move a skill out of the approved section when the user no longer wants it considered for resumes.
- Use role-specific experience notes to substantiate any skill in an experience bullet; this list is an eligibility control, not proof of an accomplishment.
- Do not infer synonyms, related products, or proficiency levels that are not listed or supported by the experience notes.
